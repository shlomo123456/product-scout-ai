
# Product Scout AI — MVP

סוכן מחקר מוצרים עם שני מצבים:

1. **מוצר ספציפי** — חיפוש מוצר, ספקים, יצרנים, מחירים ונוכחות בישראל.
2. **חיפוש רעיוני** — גילוי רעיונות למוצרים, בדיקת שוק, תחרות בישראל וסיגנלים מסחריים.

הסוכן משתמש בחיפוש ווב חי ומבקש במפורש לבדוק גם Amazon, AliExpress, Alibaba, אתרי יצרנים, סיטונאים, קמעונאים ישראליים ואתרים גדולים נוספים לפי התחום.

## הפעלה ב-Windows

1. התקן Python 3.10 ומעלה.
2. פתח Terminal / PowerShell בתיקייה הזו.
3. צור סביבה:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```
4. התקן:
   ```
   pip install -r requirements.txt
   ```
5. העתק את `.env.example` לקובץ בשם `.env`.
6. הכנס את מפתח ה-OpenAI API שלך:
   ```
   OPENAI_API_KEY=sk-...
   OPENAI_MODEL=gpt-5.6-sol
   ```
7. הפעל:
   ```
   streamlit run app.py
   ```

ייפתח מסך בדפדפן.

## מה עובד כבר ב-MVP

- חיפוש רעיוני או מוצר ספציפי
- תכנון שאילתות בעברית ובאנגלית
- חיפוש ווב חי
- דגש על Amazon / AliExpress / Alibaba
- בדיקת אתרים ישראליים
- בדיקת יצרנים / סיטונאים / קמעונאים
- איסור המצאת מחיר
- דו"ח בעברית
- טבלאות השוואה
- קישורי מקורות
- הורדת דו"ח Markdown

## מגבלה חשובה של גרסה זו

Amazon, AliExpress ו-Alibaba נבדקים דרך חיפוש הווב ודפי אינטרנט שנגישים למחקר.
זה **אינו עדיין חיבור API ישיר ומאומת לכל marketplace**. חיבור API ייעודי יכול בהמשך לשפר עקביות של מחיר, וריאציות, MOQ, זמינות ומשלוח.

ב-Amazon מומלץ לעבור בהמשך לחיבור רשמי מתאים כאשר יש חשבון והרשאות.
ב-marketplaces אחרים נבחן APIs רשמיים/שותפים בהתאם לזמינות ולהרשאות.
